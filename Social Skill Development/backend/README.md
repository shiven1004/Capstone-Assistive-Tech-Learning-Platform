# Social Skills Assessment Frontend

## Quick Start

1. **Install dependencies:**
```bash
pip install -r backend/requirements.txt
```

2. **Run the server:**
```bash
uvicorn backend.app.main:app --reload --port 8000
```

3. **Open in browser:**
```
http://localhost:8000
```

## Features
- Voice-based Q&A
- Real-time speech recognition
- LLM feedback
- Image support
- Skills assessment
- Clean, responsive interface
- 14pt font for readability

## Architecture
- FastAPI backend
- HTML/CSS frontend
- Web Speech API for voice
- Integration with existing modules
